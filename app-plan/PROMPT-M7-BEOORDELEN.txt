VASTE KEUZES
1. Een beoordeling maken gaat via de gewone API (createRule bestaat al:
   alleen bij afgerond, alleen deelnemers, een per klus per kant via de
   unieke index). Dubbel -> nette melding "U heeft al een beoordeling
   gegeven."
2. REPUTATIE ZICHTBAAR MAKEN (backend punt 12, optie a): twee velden
   erbij op hh_users: sterren_gemiddeld (getal 0-5) en klussen_aantal
   (geheel getal), script 20. Niemand mag ze via de API zetten
   (rules-script 21: niet meesturen, ook niet bij registreren).
   De hook rekent ze uit: na aanmaken of wijzigen van een beoordeling
   het gemiddelde van alle beoordelingen naar_gebruiker = die persoon
   (afgerond op 1 decimaal) en het aantal afgeronde klussen, en schrijft
   ze op hh_users EN op hh_profielen (jongere). Rekenen op de server,
   nooit in de app.
3. Beoordeling wijzigen mag (rule bestaat), verwijderen niet.
4. O9 voor de oudere: eerst duim omhoog / duim omlaag als twee grote
   knoppen, daarna sterren 1-5 als grote tikvlakken, tekst optioneel.
   Duim is alleen een opstapje in de app (omhoog = sterren voorgevuld
   op 5, omlaag = 2); opgeslagen wordt alleen sterren + tekst.
   De oudere ziet nergens gemiddelden of aantallen (ouderenregel).
5. Familie beoordeelt niet namens de oudere (backend punt 14) ->
   open punt, niet bouwen.
