Een tweede agent werkt TEGELIJK in dezelfde git-root en dezelfde app/.
Daarom:

EIGEN BESTANDEN, GEEN GEDEELDE
- Routes: NIET in lib/app/router.dart bouwen. Maak in je eigen feature-map
  een bestand <feature>_routes.dart met `List<RouteBase> <feature>Routes()`
  en voeg in router.dart precies EEN regel toe (import + spread `...`).
  Lees router.dart opnieuw vlak voordat je die regel toevoegt.
- Paden: eigen klasse in eigen bestand (bv. HhPadenJongere in
  lib/features/jongere/paden_jongere.dart). lib/app/paden.dart niet
  aanraken, behalve als een guard-set echt jouw pad nodig heeft; dan
  minimaal en na opnieuw lezen.
- Teksten: eigen bestand lib/l10n/teksten_<feature>_nl.dart.
  teksten_nl.dart alleen lezen.
- Gateway: eigen gateway-bestand(en) in lib/core/pb/ (bv.
  profiel_gateway.dart + fake). auth_gateway.dart, pocketbase_gateway.dart
  en gateway_providers.dart alleen uitbreiden met minimale regels, na
  opnieuw lezen. Nooit herschrijven.
- pubspec.yaml: alleen je eigen dependency-regels toevoegen, na opnieuw
  lezen; daarna `flutter pub get`.
- OPEN-PUNTEN: NIET app/OPEN-PUNTEN.txt bewerken. Schrijf
  app/OPEN-PUNTEN-<M3|M4>.txt. Wordt later samengevoegd.
- Backend: eigen scriptnummers (staat in je prompt). 00-04 niet wijzigen.
  backend/SCHEMA.txt: alleen je eigen sectie(s) aanvullen, na opnieuw
  lezen, minimale edit.

ALS DE ANDER JE BREEKT
- flutter analyze of test faalt in bestanden die niet van jou zijn:
  60 seconden wachten, opnieuw. Drie keer mis: sluit die bestanden uit
  in je verslag en ga door met je eigen tests (`flutter test test/<jouw map>`).
  Nooit andermans code "repareren".
- index.lock: 2 seconden wachten, opnieuw. Nooit verwijderen.

GIT
- Nooit git add -A. Nooit `-- app` als pathspec (dat veegt de ander mee).
- Stage en commit met een EXPLICIETE lijst van je eigen paden, bv.
  git -C "/Users/h/Desktop/huidige projecten/buurthulp" add app/lib/features/jongere app/test/... app/lib/l10n/teksten_jongere_nl.dart
  git -C "/Users/h/Desktop/huidige projecten/buurthulp" commit -m "feat: ..." -- app/lib/features/jongere app/test/... 
- Gedeelde bestanden (router.dart, pubspec.yaml, pubspec.lock,
  gateway_providers.dart, ios/Podfile.lock) commit je in een APARTE
  laatste commit "chore: M<n> koppelen in router/pubspec" met alleen die
  paden, nadat je eigen commits binnen zijn.
